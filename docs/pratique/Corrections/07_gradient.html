Correction – Approximation locale avec le gradient

On veut montrer que pour de petits déplacements (Delta x, Delta y) :

f(x+Δx,y+Δy)≈f(x,y)+∇f(x,y)⋅(Δx,Δy)f(x+\Delta x, y+\Delta y)\approx f(x,y) + \nabla f(x,y)\cdot (\Delta x,\Delta y) f(x+Δx,y+Δy)≈f(x,y)+∇f(x,y)⋅(Δx,Δy)

C'est la formule de linéarisation : on approche la fonction par son plan tangent.

Corrections 02 / 8

Calcul du gradient

Pour

f(x,y)=x2+2y,f(x,y)= x^2 + 2y, f(x,y)=x2+2y,

on calcule les dérivées partielles :

∂f∂x=2x,∂f∂y=2.\frac{\partial f}{\partial x} = 2x, \qquad \frac{\partial f}{\partial y} = 2. ∂x∂f​=2x,∂y∂f​=2.

Donc :

∇f(x,y)=(2x,2).\nabla f(x,y) = (2x, 2). ∇f(x,y)=(2x,2).

Corrections 03 / 8

2. Gradient au point ((1,1))

∇f(1,1)=(2⋅1,2)=(2,2).\nabla f(1,1) = (2\cdot 1, 2) = (2,2). ∇f(1,1)=(2⋅1,2)=(2,2).

Corrections 04 / 8

3. Produit scalaire avec ((\Delta x,\Delta y))

On prend :

(Δx,Δy)=(0.1,−0.2).(\Delta x,\Delta y) = (0.1, -0.2). (Δx,Δy)=(0.1,−0.2).

Produit scalaire :

∇f(1,1)⋅(Δx,Δy)=2(0.1)+2(−0.2)=0.2−0.4=−0.2.\nabla f(1,1)\cdot (\Delta x,\Delta y) = 2(0.1) + 2(-0.2) = 0.2 - 0.4 = -0.2. ∇f(1,1)⋅(Δx,Δy)=2(0.1)+2(−0.2)=0.2−0.4=−0.2.

4. Valeur approximée

f(1,1)=12+2⋅1=3.f(1,1) = 1^2 + 2\cdot 1 = 3. f(1,1)=12+2⋅1=3.

Approximation linéaire :

f(1+Δx,1+Δy)≈3+(−0.2)=2.8.f(1+\Delta x,1+\Delta y) \approx 3 + (-0.2) = 2.8. f(1+Δx,1+Δy)≈3+(−0.2)=2.8.

5. Vérification exacte

Calculons exactement :

f(1.1,0.8)=(1.1)2+2(0.8)f(1.1, 0.8) = (1.1)^2 + 2(0.8) f(1.1,0.8)=(1.1)2+2(0.8)

=1.21+1.6=2.81.= 1.21 + 1.6 = 2.81. =1.21+1.6=2.81.

Conclusion

L'approximation locale donne :

2.8\boxed{2.8} 2.8​

2.81\boxed{2.81} 2.81​

L'erreur est très petite :
la linéarisation fonctionne très bien pour de petits déplacements.
