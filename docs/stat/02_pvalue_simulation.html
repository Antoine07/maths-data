Du dé à la p-value

Une pratique avant les formules : simuler ce qu'on pourrait observer si le dé était équilibré, puis situer notre résultat dans cette distribution.

Pratique · Inférence 02 / 10

Une question concrète

On lance un dé 100 fois et on observe 25 six. Est-ce surprenant ?

On commence par préciser ce qu'on teste :

  • H0:p6=1/6H_0 : p_6=1/6H0​:p6​=1/6 — la probabilité d'obtenir un six est celle d'un dé équilibré ;
  • H1:p6>1/6H_1 : p_6>1/6H1​:p6​>1/6 — on cherche spécifiquement un excès de six.

Sous H0H_0H0​, le nombre moyen de six est 100/6≈16,7100/6\approx16{,}7100/6≈16,7. Il ne doit pas forcément être égal à 17 dans chaque série.

Limite du test : vérifier p6=1/6p_6=1/6p6​=1/6 ne suffit pas à prouver que les six faces sont toutes équiprobables. On ne teste ici que la fréquence des six.

Pratique · Inférence 03 / 10

Pratique 1 · Simuler le dé équilibré

On simule 20 000 expériences de 100 lancers sous H0H_0H0​. Chaque ligne du tableau représente une expérience ; on compte les six sur chaque ligne.

import numpy as np

rng = np.random.default_rng(2026)
n_lancers = 100
n_simulations = 20_000

tirages = rng.integers(
    1, 7, size=(n_simulations, n_lancers), dtype=np.int8
)
resultats = (tirages == 6).sum(axis=1)

print("Moyenne simulée :", resultats.mean())
print("Écart-type simulé :", resultats.std())

La moyenne théorique est 100/6≈16,7100/6\approx16{,}7100/6≈16,7 six ; l'écart-type théorique vaut 100×(1/6)×(5/6)≈3,73\sqrt{100\times(1/6)\times(5/6)}\approx3{,}73100×(1/6)×(5/6)​≈3,73.

Pratique · Inférence 04 / 10

Pratique 2 · Une valeur exacte n'est pas une p-value

Dans les simulations, on peut estimer :

  • P(X=25)P(X=25)P(X=25) : la proportion d'expériences qui donnent exactement 25 six ;
  • P(X≥25)P(X\geq25)P(X≥25) : la proportion qui donnent 25 six ou davantage.
six_observes = 25

p_exactement_25 = np.mean(resultats == six_observes)
p_unilaterale = np.mean(resultats >= six_observes)

print("P(X = 25), estimée :", p_exactement_25)
print("P(X >= 25), estimée :", p_unilaterale)

La p-value unilatérale est P(X≥25∣H0)P(X\geq25\mid H_0)P(X≥25∣H0​), ici estimée par P(X≥25)P(X\geq25)P(X≥25) dans nos simulations sous H0H_0H0​. Elle additionne la probabilité de 25 et celles des résultats plus élevés : ce n'est pas P(X=25)P(X=25)P(X=25) seul.

Pour repère, le calcul binomial exact donne environ 0,98 % pour P(X=25)P(X=25)P(X=25) et 2,17 % pour P(X≥25)P(X\geq25)P(X≥25). La simulation fournit une approximation qui varie légèrement d'une exécution à l'autre.

Pratique · Inférence 05 / 10

Pourquoi choisir un seuil de 5 % ?

On fixe d'abord α=5%\alpha=5\%α=5%. C'est le taux maximal visé de fausses alertes : si H0H_0H0​ est vraie et qu'on répète la même procédure, un test bien calibré rejette H0H_0H0​ dans au plus 5 % des cas.

Ce seuil ne signifie ni que H0H_0H0​ a 5 % de chances d'être vraie, ni que notre conclusion présente exactement 5 % de risque d'être fausse.

Pour le test unilatéral avec 25 six :

p-value≈2,17%<5%.p\text{-value}\approx2{,}17\% < 5\%. p-value≈2,17%<5%.

On rejette donc H0H_0H0​ au seuil de 5 %, en faveur d'un excès de six. Avec cette loi discrète, le seuil réel de fausse alerte peut être inférieur à 5 % : on ne peut pas toujours atteindre exactement le seuil choisi.

Pratique · Inférence 06 / 10

Pratique 3 · Une ou deux directions ?

Le choix dépend de la question posée avant de regarder le résultat :

  • Unilatéral : H1:p6>1/6H_1:p_6>1/6H1​:p6​>1/6. Seuls les excès de six comptent ; pour 25 six, la p-value vaut environ 2,17 %.
  • Bilatéral : H1:p6≠1/6H_1:p_6\ne1/6H1​:p6​=1/6. Un déficit ou un excès important compte. Ici, on compare la distance au nombre moyen 100/6100/6100/6 :

pbilat=P ⁣(∣X−1006∣≥∣25−1006∣)≈3,12%.p_{\mathrm{bilat}}=P\!\left(\left|X-\frac{100}{6}\right|\geq\left|25-\frac{100}{6}\right|\right)\approx3{,}12\%. pbilat​=P(​X−6100​​≥​25−6100​​)≈3,12%.

Les deux p-values sont sous 5 % pour 25 six. Mais avec 24 six, elles sont environ 3,79 % en unilatéral et 5,92 % en bilatéral : la conclusion au seuil de 5 % change. Il faut donc choisir la direction avant l'expérience.

Pratique · Inférence 07 / 10

Visualiser les résultats comptés

On colorie en rouge les résultats inclus dans chaque p-value : à droite pour le test unilatéral ; des deux côtés pour le test bilatéral.

import matplotlib.pyplot as plt

x = np.arange(n_lancers + 1)
probas = np.bincount(resultats, minlength=n_lancers + 1) / n_simulations
moyenne = n_lancers / 6
distance = abs(six_observes - moyenne)

unilaterale = x >= six_observes
bilaterale = np.abs(x - moyenne) >= distance

fig, axes = plt.subplots(1, 2, figsize=(12, 4))
for ax, masque, titre in [
    (axes[0], unilaterale, "Unilatéral : X ≥ 25"),
    (axes[1], bilaterale, "Bilatéral : résultats aussi éloignés"),
]:
    couleurs = np.where(masque, "tomato", "steelblue")
    ax.bar(x, probas, color=couleurs)
    ax.axvline(moyenne, color="green", linestyle="--", label="Moyenne sous H₀")
    ax.axvline(six_observes, color="black", linestyle=":", label="25 six observés")
    ax.set(xlim=(0, 40), xlabel="Nombre de six sur 100", ylabel="Probabilité simulée", title=titre)
    ax.legend()
fig.tight_layout()
plt.show()

Pratique · Inférence 08 / 10

Ce qu'une petite p-value permet de dire

Une petite p-value indique que le résultat observé — ou un résultat plus extrême selon le test choisi — est rare si H0H_0H0​ et les hypothèses du modèle sont vraies.

Elle ne donne pas la probabilité que H0H_0H0​ soit vraie. Et ne pas rejeter H0H_0H0​ ne prouve pas que le dé est équilibré : cela signifie seulement que les données ne suffisent pas à l'écarter avec ce test.

Les p-values données par simulation sont des estimations. Augmenter n_simulations les stabilise ; près du seuil de 5 %, il faut éviter de conclure à partir d'une simulation trop courte.

Le test bilatéral compte aussi les résultats suffisamment éloignés de la moyenne du côté inférieur ; sa p-value vaut environ 5,92 % : on ne rejette pas H0H_0H0​ à ce seuil.

Pratique · Inférence 10 / 10

Prolongement · Quand la loi est symétrique

Le nombre de six suit ici une loi binomiale qui n'est pas exactement symétrique. Pour une loi symétrique autour de 0, comme la loi normale centrée réduite, les deux côtés ont la même probabilité :

P(∣Z∣≥∣zobs∣)=2P(Z≥∣zobs∣).P(|Z|\geq|z_{\mathrm{obs}}|)=2P(Z\geq|z_{\mathrm{obs}}|). P(∣Z∣≥∣zobs​∣)=2P(Z≥∣zobs​∣).

Nous réutiliserons cette idée avec une loi symétrique : un test bilatéral examine alors deux queues de même aire.
