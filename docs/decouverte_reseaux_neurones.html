Le perceptron en un coup d’œil

Un perceptron transforme des entrées en une décision : il pondère les caractéristiques, additionne leurs contributions avec un biais, puis compare le score à un seuil. Il résume les opérations que nous allons coder, une observation à la fois.

Échauffement · Le produit scalaire d’un panier

Le produit scalaire de deux vecteurs de même dimension est le nombre obtenu en multipliant leurs coordonnées de même rang, puis en additionnant les produits. Pour deux vecteurs aaa et bbb à trois coordonnées, on écrit

a⋅b=a1b1+a2b2+a3b3.a\cdot b=a_1b_1+a_2b_2+a_3b_3. a⋅b=a1​b1​+a2​b2​+a3​b3​.

Dans une liste de courses, on associe à chaque produit sa quantité et son prix unitaire.

Produit Prix (€) Quantité
Sachet de pommes 2 2
Bouteille de lait 1 1
Pain 3 1

On garde le même ordre dans les deux vecteurs. Pour les quantités q=(2,1,1)q=(2,1,1)q=(2,1,1) et les prix p=(2,1,3)p=(2,1,3)p=(2,1,3), le total vaut

q⋅p=2×2+1×1+1×3=8 euros.\begin{aligned} q\cdot p &= 2\times 2+1\times 1+1\times 3\\ &= 8\ \text{euros}. \end{aligned} q⋅p​=2×2+1×1+1×3=8 euros.​

Découverte · IA 06 / 13

Un neurone calcule un score

On donne au neurone deux caractéristiques numériques, x1x_1x1​ et x2x_2x2​. Il leur associe des poids w1w_1w1​ et w2w_2w2​, puis ajoute un biais bbb :

z=w1x1+w2x2+b.z=w_1x_1+w_2x_2+b. z=w1​x1​+w2​x2​+b.

Le score zzz résume les entrées selon les poids choisis par le modèle. Une règle de décision transforme ensuite ce score en classe.

En NumPy, l'opérateur @ calcule un produit matriciel. Quand ses deux côtés sont des vecteurs de même longueur, il calcule leur produit scalaire : il multiplie les coordonnées correspondantes, puis additionne les produits.

import numpy as np

x = np.array([2, 1])
poids = np.array([1, -2])
produit = x @ poids  # 2 × 1 + 1 × (-2) = 0
score = produit + 1  # le biais vaut 1, donc le score vaut 1

Dans notre perceptron, le score s'écrit donc x @ poids + biais. Pour une matrice X contenant plusieurs observations, X @ poids calcule en une fois un score par ligne.

On note y^\widehat yy​, prononcé « y chapeau », la classe que le modèle prédit. Le chapeau indique ici une valeur estimée par le modèle. La lettre yyy sans chapeau désigne la classe attendue, connue dans les données. La prédiction peut être correcte (y^=y\widehat y=yy​=y) ou erronée (y^≠y\widehat y\ne yy​=y).

La règle de décision est :

y^={1si z≥0,0si z<0.\widehat y=\begin{cases}1 & \text{si } z\geq 0,\\ 0 & \text{si } z<0.\end{cases} y​={10​si z≥0,si z<0.​

Cette règle porte le nom de fonction escalier : elle transforme un score en classe 0 ou 1.

def fonction_escalier(score):
    return int(score >= 0)

Les poids disent quelles caractéristiques font monter ou baisser le score. Le biais déplace le seuil de décision.

Découverte · IA 08 / 13

Une frontière sépare les deux classes

Dans un repère, une droite s'écrit souvent y=ax+by=ax+by=ax+b. Ici, les deux axes représentent les caractéristiques x1x_1x1​ et x2x_2x2​ : on écrit donc plutôt x2=ax1+cx_2=ax_1+cx2​=ax1​+c. Cette droite partage le plan en deux demi-plans. Le signe du score indique de quel côté se trouve un point et donc quelle classe le perceptron prédit.

Avec deux caractéristiques, la frontière vérifie w1x1+w2x2+b=0w_1x_1+w_2x_2+b=0w1​x1​+w2​x2​+b=0 (si w2≠0w_2\neq0w2​=0, on peut isoler x2x_2x2​). Elle contient les points dont le score vaut zéro.

Reprenons l'exercice 1 avec le biais initial b=1b=1b=1. Le score est z=x1−2x2+1z=x_1-2x_2+1z=x1​−2x2​+1. En posant z=0z=0z=0 et en isolant x2x_2x2​, on obtient

x2=x1+12.x_2=\frac{x_1+1}{2}. x2​=2x1​+1​.

Le point (2,1)(2,1)(2,1) de l'exercice a un score de 111. Il est sous la droite, dans la classe 1. La règle z≥0z\geq 0z≥0 inclut aussi les points de la droite dans cette classe.

Découverte · IA 09 / 13

Lire le rôle des poids

Reprenons le score :

z=w1x1+w2x2+b.z=w_1x_1+w_2x_2+b. z=w1​x1​+w2​x2​+b.

  • Si un poids est positif, augmenter la caractéristique correspondante augmente le score.
  • Si un poids est négatif, l'augmenter diminue le score.
  • Le biais bbb déplace la frontière sans changer son orientation.

Ces effets dépendent de l'échelle des caractéristiques. Pour l'instant, nous choisissons de petits nombres faciles à comparer.

Découverte · IA 11 / 13

Comment le perceptron apprend-il ?

Dans les données, yyy est la classe attendue. y^\widehat yy​, prononcé « y chapeau », est la classe prédite par le perceptron. On compare les deux ; si elles diffèrent, on modifie légèrement les poids dans le sens de l'exemple :

w←w+η(y−y^)x,b←b+η(y−y^).\mathbf w\leftarrow\mathbf w+\eta(y-\widehat y)\mathbf x, \qquad b\leftarrow b+\eta(y-\widehat y). w←w+η(y−y​)x,b←b+η(y−y​).

Ici, η\etaη est un petit nombre positif appelé pas d'apprentissage. La formule ne demande que des additions et des multiplications.

La différence y−y^y-\widehat yy−y​ indique le sens de la correction. Par exemple, si la classe attendue est y=0y=0y=0 mais que le modèle prédit y^=1\widehat y=1y​=1, alors y−y^=0−1=−1y-\widehat y=0-1=-1y−y​=0−1=−1.

  • Si la prédiction est juste, y=y^y=\widehat yy=y​ et la différence vaut 000 : les paramètres ne changent pas.
  • Si la vraie classe vaut 111 mais que le modèle prédit 000, la différence vaut +1+1+1 : le score de cet exemple est poussé vers le haut.
  • Si la vraie classe vaut 000 mais que le modèle prédit 111, la différence vaut −1-1−1 : le score est poussé vers le bas.

Le vecteur x\mathbf{x}x répartit cette correction entre les poids, tandis que le biais reçoit la correction directement. C'est une règle de mise à jour simple du perceptron, pas un calcul de dérivée.

Exemple guidé. On prend x=(1,0)\mathbf x=(1,0)x=(1,0), y=0y=0y=0, y^=1\widehat y=1y​=1, η=0,2\eta=0{,}2η=0,2, w=(0,2,0,1)\mathbf w=(0{,}2,0{,}1)w=(0,2,0,1) et b=−0,1b=-0{,}1b=−0,1. Le facteur (y−y^)(y-\widehat y)(y−y​) vaut −1-1−1 : le poids associé à la première caractéristique et le biais diminuent.

Découverte · IA 12 / 13

Une correction, pas à pas

Dans l'exemple précédent, le facteur de correction vaut :

η(y−y^)=0,2(0−1)=−0,2.\eta(y-\widehat y)=0{,}2(0-1)=-0{,}2. η(y−y​)=0,2(0−1)=−0,2.

On applique ce facteur à chaque composante de x=(1,0)\mathbf x=(1,0)x=(1,0) :

wnouveau=(0,2,0,1)−0,2(1,0)=(0,0,1),bnouveau=−0,1−0,2=−0,3.\mathbf w_{nouveau}=(0{,}2,0{,}1)-0{,}2(1,0)=(0,0{,}1), \qquad b_{nouveau}=-0{,}1-0{,}2=-0{,}3. wnouveau​=(0,2,0,1)−0,2(1,0)=(0,0,1),bnouveau​=−0,1−0,2=−0,3.

Pour cette observation, le nouveau score est −0,3-0{,}3−0,3. La classe prédite devient 0. On vient de corriger cet exemple ; il faudra vérifier les autres exemples avant de conclure que le modèle est prêt.

Entraîner le perceptron, manchot par manchot

Vous avez maintenant les caractéristiques X et la classe attendue y. Le perceptron va parcourir les lignes une par une. Pour chaque manchot, il calcule un score, prédit une espèce, compare sa prédiction à la cible, puis corrige ses paramètres en cas d'erreur.
