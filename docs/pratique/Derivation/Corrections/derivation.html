Exercice 3

Trouver les points critiques.

a) f(x,y)=x2+y2−4xf(x,y)=x^2 + y^2 - 4xf(x,y)=x2+y2−4x

Gradient :

fx=2x−4,fy=2y.f_x = 2x - 4,\quad f_y = 2y. fx​=2x−4,fy​=2y.

Point critique :

2x−4=0⇒x=2,2y=0⇒y=0.2x-4=0 \Rightarrow x=2,\qquad 2y=0 \Rightarrow y=0. 2x−4=0⇒x=2,2y=0⇒y=0.

Point critique : ((2,0)).

Classification : déjà montrée précédemment → minimum local.

H=(20 0−2).H= \begin{pmatrix} 2 & 0\ 0 & -2 \end{pmatrix}. H=(2​0 0​−2​).

fx=3,fy=2.f_x=3,\qquad f_y=2. fx​=3,fy​=2.

Interprétation :

  • augmenter (x) fait croître la fonction trois fois plus fortement qu’une variation de même amplitude sur (y),
  • (x) a donc un impact plus important que (y) sur la valeur de (f).

Exercice 1

f(x,y)=x2+xy+y2.f(x,y)=x^2 + xy + y^2. f(x,y)=x2+xy+y2.

1) Gradient

fx=2x+y,fy=x+2y.f_x = 2x + y,\qquad f_y = x + 2y. fx​=2x+y,fy​=x+2y.

Point critique :

2x+y=0,x+2y=0.2x+y=0,\quad x+2y=0. 2x+y=0,x+2y=0.

Résolution :

De (2x+y=0), on a (y = -2x).
Remplacer dans (x+2y=0) :

x+2(−2x)=0⇒x−4x=0⇒−3x=0⇒x=0.x + 2(-2x)=0 \Rightarrow x - 4x = 0 \Rightarrow -3x = 0 \Rightarrow x=0. x+2(−2x)=0⇒x−4x=0⇒−3x=0⇒x=0.

Donc (y=-2x=0).

Point critique : ((0,0)).

2) Hessienne

fxx=2,fyy=2,fxy=1.f_{xx}=2,\quad f_{yy}=2,\quad f_{xy}=1. fxx​=2,fyy​=2,fxy​=1.

H=(21 12).H= \begin{pmatrix} 2 & 1\ 1 & 2 \end{pmatrix}. H=(2​1 1​2​).

Déterminant :

D=2⋅2−12=4−1=3>0.D = 2\cdot 2 - 1^2 = 4 - 1 = 3 > 0. D=2⋅2−12=4−1=3>0.

Comme fxx=2>0f_{xx} = 2 > 0fxx​=2>0, conclusion :

Minimum local.

Exercice 2

g(x,y)=x3−3xy+y3.g(x,y)=x^3 - 3xy + y^3. g(x,y)=x3−3xy+y3.

Gradient

gx=3x2−3y,gy=−3x+3y2.g_x=3x^2 - 3y,\qquad g_y=-3x + 3y^2. gx​=3x2−3y,gy​=−3x+3y2.

Point critique : résoudre

3x2−3y=0,−3x+3y2=0.3x^2 - 3y = 0,\qquad -3x + 3y^2 = 0. 3x2−3y=0,−3x+3y2=0.

Simplification :

x2=y,y2=x.x^2 = y,\qquad y^2 = x. x2=y,y2=x.

On remplace :

(x^2 = y) dans (y^2 = x) :

(x2)2=x⇒x4=x⇒x(x3−1)=0.(x^2)^2 = x \Rightarrow x^4 = x \Rightarrow x(x^3 - 1)=0. (x2)2=x⇒x4=x⇒x(x3−1)=0.

Solutions :

  1. (x=0 \Rightarrow y=0).
  2. (x^3 = 1 \Rightarrow x=1) et donc (y=1).

Points critiques : ((0,0)) et ((1,1)).

Hessienne :

gxx=6x,gyy=6y,gxy=−3.g_{xx}=6x,\quad g_{yy}=6y,\quad g_{xy}=-3. gxx​=6x,gyy​=6y,gxy​=−3.

Au point (0,0)

H=(0−3 −30).H= \begin{pmatrix} 0 & -3\ -3 & 0 \end{pmatrix}. H=(0​−3 −3​0​).

D=0⋅0−(−3)2=−9<0.D = 0\cdot 0 - (-3)^2 = -9 < 0. D=0⋅0−(−3)2=−9<0.

Donc : point selle.
